# Heavy Cleave · 独立高清重击剑光

作者范围：只要重击剑光，其他的不要。保留原 `melee/heavy-cleave`；本稿没有人物、武器、蓄力闪点、落地爆闪、裂纹、烟尘、碎石、火星或独立光点。

## 原效果拆解

原稿的前 0.2 秒是举剑闪点。其后的剑光由倾斜椭圆上的厚弧与内侧细弧组成：中心 `(3,-22)`、半径 37、纵向压缩 0.88、旋转 0.32 弧度、起始角 -2.45 弧度；顺时针挥到虚拟接触面前。主弧厚度 16，细弧半径比 0.76、厚度 5、延迟 20 ms。

主弧用平方曲线加速，135 ms 到达终点、保持 50 ms，然后尾端在 220 ms 内追上刃尖。新稿移除蓄力起始段，将挥砍开始归零；保留这些相对节奏。原版命中的 0.2 秒顿帧属于人物演出，不加入独立剑光时钟。

## 高清分层

| 层 | 表现与运动 |
| --- | --- |
| 橙红厚弧 | 重新绘制抗锯齿曲线与不等宽色带；前轻后重，尾端追赶刃尖 |
| 白热刃缘 | 窄奶白外缘与局部断续亮笔；随主弧退热 |
| 手绘笔触 | 顺挥砍方向的长短色块、细干笔与错开的内沿缺口；与剑光贴合 |
| 内侧细弧 | 相同弧面、0.76 半径、20 ms 延迟；无独立漂浮粒子 |
| 贴边微光 | 低强度加法光，仅贴着剑弧；不产生落地光池 |

源码：`src/hd/heavy-cleave.js`；预览：`gallery/hd-heavy-cleave.html`。
逻辑画幅 1024×768，锚点 `(440,635)`，一次播放窗口 0.52 秒，60 FPS；首尾透明。固定 seed=5。
画风采用实时重绘的手绘色带与笔触几何，没有参考像素放大、整效果帧动画或播放图集。
深浅背景先画入预览，再合成色层与加法微光；`color.png` 仅保存普通 Alpha 色层。

## 三轮审稿

1. round1：验证独立厚弧、内侧细弧与原稿加速/停留/收尾时序。发现早期刃尖过厚、内部细线过于规整。
2. round2：收窄早期刃尖，将内部线改成长短不齐的笔触，增加内沿缺口及稀疏干笔。检查深浅底色与小尺寸；发现多层缺口同步形成折线。
3. round3：将缺口改为光滑曲线并错开各色带的位置，消除成排折角；复查峰值、消散、分层、不同背景和 96/192/384 px 画幅。
