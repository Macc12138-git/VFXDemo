# Heavy cleave V3 · 原版轨迹高清手绘

作者已澄清：上传的红色刀光样例只用来说明高清手绘的笔触、边缘和色块表达。作品仍然是原 Heavy cleave 的高清手绘版。V2 把样例环形轮廓带入了作品，方向错误，因此保留为历史稿，不作为当前稿。

## 保持项与重画项

- 唯一运动依据：`src/fx/melee/heavy-cleave.js`。从头后左上方起势，顺时针越顶，向右下方地面加速劈落；只提取刀光，不绘制地面、人物、武器、蓄力闪光、爆点、尘土、碎石和火星。
- 原版弧面参数：中心 `(3,-22)`、半径 37、纵向压缩 0.88、旋转 0.32、起角 -2.45、方向 +1，依原版循环判定在 y=-0.5 附近终止。高清统一缩放 `320/37`，锚点 `(388,650)`；不独立 fit、镜像或转向。
- 原版时间：移除 0.2 秒无关蓄力段后，135 ms 加速挥出、50 ms 停留、220 ms 尾部追赶；内弧余影仍落后 20 ms。预览时间加 0.2 即为原版源码时间。
- 重画：前端保留整刀长度的宽切面，不捏成尖点；稳定外弧配窄亮刃。以明确切口、分叉与断笔重画内沿后段；不使用正弦或噪声扰动轮廓。前段保持整块，撕裂集中在较老的左上拖尾。
- 三类颜色：暖橙主色 `#f47732`、局部暗笔 `#9d302b`、奶白亮刃 `#fff3d1`，各自独立可调。少量贴边加法微光独立分层；不增加整圈渐变带。

## 三轮观察与调整

1. round1 / 3.0.0：恢复原版准确轨迹、方向、弧面和时序，加入同尺度原版刀光对照。逐时相对照确认挥砍一致；发现前半段硬切缺口较多，削弱了宽阔刀面。
2. round2 / 3.0.1：把两处主要撕裂移到较老的后半段，去除前段的小锯口；保留完整宽头。检查深浅底、透明底及 96/192/384 px 画幅；观察到内弧余影仍过于连贯。
3. final / 3.0.2：将内弧余影的旧尾端分成两段不等长断笔，保持原 0.76 半径及 20 ms 延迟。复核主弧、宽头、后段负形与原速/慢放对照。

## 对照与检查

`src/hd/heavy-cleave-reference.js` 只重放原版的两条刀光 arc：调用原 melee helper，保留原始 palette、宽度、冷却与贴边光公式。未重放其他图层。左侧像素稿 nearest 展示；右侧高清几何按正常抗锯齿绘制，两者共用缩放、锚点和时钟。

各轮静态图、源码快照、运动对照和检查见对应目录。轨迹与原 helper 在多个时相数值对照；同时检查首尾透明、确定性、图层开关、独立调色、实际宽头横截面、三色覆盖和刀长 140–240 的画幅边界。量化结果用于诊断，作者视觉验收尚待反馈。

入口：`gallery/hd-heavy-cleave-v3.html`。默认原版同步对照，可切换仅看高清稿；支持原速/慢放、逐帧、关键时相、背景与小尺寸检查。V1/V2 源码、记录和预览均保留。
