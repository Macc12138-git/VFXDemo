# Heavy Cleave V2 · 宽刃撕裂刀光

> 历史稿，已由 V3 替换。作者随后澄清上传样例只用于说明高清手绘画法，不用于改变 Heavy cleave 的方向和轨迹；本稿的环形造型不作为当前交付。见 `../V3/AUTHORING.md`。

## 作者约束与参考

只制作斩击刀光。前端宽度表达一整把刀的长度，保持宽阔切面；外弧有锋利亮边，主弧稳定。内沿和后段用硬切缺口、分叉与断笔表现撕裂，避免连续波浪。将像素抗锯齿过渡色归并为少量大色块。

作者提供的单图以 `../References/slash-shape-template.jpg` 保存，仅用于造型对照。图中可观察到宽阔前端、上方大色块、内沿切口与逐渐拉细的后段；运动方向及时间不能由这张静图证明。

本次对话已对齐以左侧宽口为前端、沿弧回卷的部分为拖尾。配色继续使用原 Heavy cleave 的暖橙红方向；新增奶白切刃亮边。动态采用快速挥出、短停、收尾的制作解释，沿用旧稿 135 ms 挥出、50 ms 停留，后段约 250 ms 收尾。没有采样图像作为运行帧，没有生成 GIF 或播放图集。

## 表现选择

- 形状：半径 300 的稳定主弧，宽前端逐渐收成后段；默认刀长 192。前端以两段明确切面收口，不将头部捏成尖点。
- 色块：主色 `#f36b32`、局部暗笔 `#9d302b`、亮边 `#fff3d1`。暗笔只占局部区域；没有整圈渐变带或嵌套多圈描边。
- 撕裂：手工 Bézier 负形切口、少量硬折角与断开的同弧拖尾。没有正弦或噪声轮廓扰动。
- 微光：独立、低强度加法层，默认 0.12；不承担主体造型。
- 时钟：基于实例年龄秒数，0.52 秒窗口，60 FPS，首尾透明。纯函数重绘，无随机项。
- 范围：无人物、武器、落地爆闪、烟尘、裂纹、碎石或独立火星。没有 Unity 资产或场景修改。

## 三轮审稿

1. round1 / 2.0.0：建立宽头、稳定外弧、三类色块与内侧撕裂。对照发现后段断面过于平直，前端可进一步加宽。
2. round2 / 2.0.1：刀长 176 → 192，前端加入两段明确切面；后段以斜向渐尖断笔替代平直管状断面。检查深浅底色与 96/192/384 px 画幅，发现内侧长笔过于顺滑。
3. final / 2.0.2：内侧长笔加入不等长分叉与硬切断口；保留干净外弧和完整宽头。复查峰值、收尾、分层、三色比例与同尺度模板对照。

## 对照与验证

模板标定中心约 `(274,290)`、外弧半径约 184；重绘中心 `(512,384)`、半径 300。静态对照按该半径比例统一缩放，没有分别自动 fit。静图仅与完整刀光时相对照。

每轮源码快照、静态图和检查结果保存在对应目录。检查包括实际渲染前端横截面宽度、主色覆盖、首尾归空、确定性、分层与调色、刀长 140–240 的画幅边界。色层峰值中约 98% 的不透明像素由三种主颜色覆盖；边缘抗锯齿像素不构成额外设计色带。
