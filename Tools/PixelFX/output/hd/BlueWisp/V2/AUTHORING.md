# 苍蓝灵火 V2 制作记录

状态：2026-11-11，高清 Canvas 重绘原稿，等待作者视觉验收。没有 Unity 导入授权；
本轮未修改 Assets、场景、skill 或旧版源码。

## 本轮输入与方向

作者指出旧稿周期波动夸张，随后要求按调整后的代码与方向重新绘制新效果。
参考沿用 `../References/central-orb-contact.png` 及 `reference.json`，只观察 GIF 中间蓝球。
参考帧不作为播放素材；无 GIF、无序列帧、无角色或额外场景。

- 固定球体大小、锚点、白热核心和左侧主轮廓。
- 手绘感来自不对称色块、粗细笔触与断续边缘，不来自全局摆动。
- 右侧三处短焰片错开剥离，少量碎光向右漂移；不叠加整体呼吸缩放。
- 三处局部循环在 1.4 秒总周期内分别发生 3、4、5 次，强度不驱动主形。

## 三轮观察与实际修改

1. `round1` / 2.0.0：重建静态球形、亮核和局部焰片模型，取消旧版全部全局缩放与摆动。
   动态、接触图和 288 个参数采样确认主体稳定。问题：亮核周围色圈仍过于均匀。
2. `round2` / 2.0.1：把均匀色圈改为偏心、不对称的底色块；拆开左侧长亮笔触。
   观察浅色、灰底和游戏尺寸；问题：碎光偏薄、偏远，小尺寸下不够接近参考的短碎焰。
3. `final` / 2.0.2：缩短碎光行程，增加深蓝底层与青色厚帽；不增大主体运动幅度。
   检查深浅/透明棋盘、48/80/128px、分层、循环和浏览器实际播放。

## 验证与边界

`tools/check-blue-wisp-v2.mjs` 进行确定性、逐项调色和参数作用、透明关闭、无裁切、
精确循环端点与邻帧接缝检查。61 个时点确认主形/笔触/亮核和左半球逐像素稳定。
288 个 seed/局部强度采样无边缘裁切；局部控制点位移上限 0.055R、弯折上限 0.0175R，
默认 localMotion=0.7；碎光独立运动，不属于主体形变范围。

浏览器观察确认 V2.0.2 实际运行，暂停、时间轴、逐帧和旧稿对照可用，控制台无 warning/error。
浏览器预览是 Canvas 原稿，并非 Unity Shader 或运行效果。
透明静帧 `transparent-color.png` 只包含颜色；加法微光须在真实背景上合成，
不能用单张 Straight RGBA PNG 代表任意底色的加法结果。

本地 Node Canvas 绘制采样不代表 Unity 性能；Unity 原生组装、批次/合批、
目标平台 CPU/GPU/内存均未测，平台、并发数量和预算未指定。
