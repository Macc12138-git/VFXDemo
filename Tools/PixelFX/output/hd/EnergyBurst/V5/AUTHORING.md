# EnergyBurst V5 — 圆形能量爆炸，电流为细节

2026-11-08。制作审阅稿，等待作者视觉验收；未导入 Unity。

## 作者要求与新设计

作者明确纠正：爆炸是圆形，电流只是其中的效果。舍弃 V4 的放射闪电主形，重新设计，不继续修改它的路径方案。

新稿主次关系：近圆形蓝白能量爆发是主体；高光收束、圆形快速扩张、翻卷破碎和消散构成完整爆炸。细短电流是独立的穿行/放电层，位于内部和前沿，随扩散向外并沿局部弧线运动。关闭电流后，主爆炸仍有完整的圆形扩散轮廓。

能量前沿是较宽、局部翻卷破裂的区域，不是只有一条细圆线。没有放射状长闪电、烟火、角色或道具。蓝白配色对齐既有能量团；本爆炸不读取或修改它的动画素材。

## 分层及参数

1. 聚集：能量收束、白热亮核增强，少量局部电流。
2. 白热爆发：扩张开始时的短促亮核，增加体积变化与冲击。
3. 蓝色能量体：近圆形扩张，中心逐渐释放，能量集中到较宽的外冲区域。
4. 翻卷亮部：实时扭曲噪声形成亮带和破碎轮廓，随扩张、流动、侵蚀和衰减变化。
5. 电流细节：短弧及局部分叉，沿前沿游走并向外穿行；不构成主轮廓。
6. 局部蓝光：独立低强度加法光，不使用真实 Light。

默认 seed=37，R=180 逻辑 px，duration=1.02s，charge=0.14 参考秒，body=1，electric=1，strength=1，glow=0.65。

配色独立：白热 `#ffffff`、主体 `#2458ff`、亮部 `#a7c6ff`、电流 `#f1f6ff`、光晕 `#1440ff`。颜色与形状、透明度分开，不是对烘焙整帧整体乘色。

默认阶段：0–0.14s 收束与高光聚集；约 0.14–0.21s 白热释放；约 0.20–0.44s 近圆形快速外冲、中心释放；约 0.40–0.75s 翻卷区域破碎，电流穿行；后段余能衰减，t=1.02s 严格为空。

时钟为单次效果年龄。`tReference = time × 1.02 / duration`；总时长等比例缩放所有阶段，charge 使用基准时间中的秒。R 按比例缩放整个视觉，包括次级电流，不包含伤害判定。页面可调 R=90–220px、时长 0.55–1.5s、聚集 0.08–0.20 参考秒。

艺术不变量：圆形主轮廓、先聚后爆、主能量先于次级细节、快速外冲与破碎收尾。seed 只改变能量纹理相位和受控次级电流的出生、位置、长短、寿命与局部弯折；不把固定 seed 的每条线当作未来 Unity 的逐节点合同。

## 材质与资源合同

本稿使用 WebGL 实时能量场＋Canvas2D 次级电流几何。它是正面 2D 体积表现，不是任意视角 3D 爆炸；不代表 Unity 实际 Shader。

噪声为一张 128×128 RGBA8 静态数据：R/G/B 为不同尺度的无缝噪声，A=1，线性数据、Repeat、双线性、无 Mipmap。单张理论像素容量 64KiB，不含浏览器多个预览面板的副本、缓冲区或 V6 已有数据。噪声 SHA256：`6ab87f18d424a1d298dcbe342fc373aa06f788fc22e3c35d63692464372a69c6`。

无新增序列帧、整效果图集或 GIF。噪声随效果年龄实时扭曲、平移和阈值侵蚀；导出 PNG 仅为审阅证据，不作为运行动画资源。

根锚点为画面中心，逻辑坐标 x 向右/y 向下，主预览 1 逻辑 px 对应 1 画布 px。CPU 参考输出将覆盖色预乘 RGB/Alpha 与加法蓝光分别计算；透明审稿图再合成为 RGBA。Canvas 显示 RGB 加法不是 Unity 线性空间验证。

## 三轮观察与改进

- round1：先建立圆形体积、翻卷亮部、独立电流和收尾。观察到体积偏实，静态纹样随球一起放大，容易读成蓝色球体，而不是爆炸。
- round2：增加内部能量图案的实时变化，削弱完整硬边，中心开始释放，电流在扩散路径上更明确地外移。圆形关系清楚，但冲击前沿不够集中，仍有放大球的感觉。
- round3 / final：更快外冲、更早释放中心，蓝色能量转移到较宽的前沿；增加不均匀白热翻卷亮部，强化短促白热爆发，缩短完整球体的停留。保留内流电流为次级层。最终增加透明边界、端点、分层与颜色检查，并对齐 CPU/GL 的弱光截断边界。

各轮保留源码快照、参数、接触图和检查。浏览器截图见 `final/QA/browser-flash.png`、`browser-spread.png`、`browser-break.png`、`browser-layers.png`。
