# EnergyBurst V3 · 窄环电流扩散

作者要求：圆环更窄、扩散细节更多；补充明确是电流能量扩散，风格不要偏离已验收能量球。2026-11-07，本轮只制作独立爆炸，不修改 EnergyCluster V6、爆炸 V1/V2、Unity 资产和场景，不生成 GIF。

## 形态与风格

主环几何厚度倍率默认 0.52（相对 V2），最大范围与 0.82s 时长保留。前沿保持近圆形，叠加低幅、连续流动的折角起伏，不把轮廓重新变成大星形。
电流沿薄壳及其近邻游走，局部岔开、向外扩散；用分段折线、短分叉、细蓝光与轻微亮度脉动表达，不添加实体碎石、符文、烟雾或新色相。
保留 V2 的膜层侵蚀与短卷片；静态噪声 B 通道用于环内细流色阶。破膜与蓝白电流共用同一套色阶，而非叠加另一套霓虹电圈。

主蓝 `#2458ff`、白热 `#ffffff`、内亮蓝 `#45b5ff` 与光色 `#1440ff` 对齐 EnergyCluster V6 默认语义配色；电弧亮芯 `#eff4ff`。这表示色彩与薄壳语言对齐，不声称已完全复现参考的手绘动画。
首端仍是独立亮核起爆，中心体积与起爆尺寸本轮未重做；原能量球不增加爆炸阶段。

## 控制项

保留 radius=180（90～240 px）、duration=0.82（0.4～1.4s）、initialSize=28、strength=1、glow=0.65、seed=37。

- `ringWidth` 默认 0.52，UI 0.25～1：只控制主环几何厚度，不缩放整体半径和电弧。
- `detailAmount` 默认 1，UI 0～1.5：控制电弧、局部分叉、轻微电流轮廓起伏与环内细流的强度。
- `details` 图层：独立开关新增电流细节，可用“只看电弧”检查。
- `detailColor`：电弧亮部独立调色，其他主形与光晕仍按原语义颜色控制。

R 仅控制视觉覆盖，不包含伤害判定。主要覆盖在 R 内，柔光至多 1.08R；t=0 与 t>=duration 为空。

## 素材与实现

仍为一张 256×256 RGBA8 静态数据，无新增图集或序列帧。R=粗形、G=侵蚀、B=细流、A=255，线性、Repeat、Bilinear、无 Mipmap，理论像素数据 256 KiB。
圆形前沿、膜片、电弧、分叉与淡出由年龄实时计算。CPU 参考与 WebGL 同步；新增电弧按 12 个受控角向区域表达，位置、持续和亮度有差异，不将其当作未来 Unity 的固定粒子节点合同。
作者预览按覆盖色与加法蓝光分别合成，尚未做 Unity Linear/HDR 或任意视角 3D 校准。

## render / look / refine

1. `round1/`：厚度改 0.52，加入外散细亮片。实际观察接触图与浏览器：环明显变窄，但亮片过于径向整齐，像短毛刺。
2. `round2/`：加入近邻短弧、放宽径向距离，利用原 B 通道增加环内细流层次。观察：细节太弱，仍偏普通能量环；此时作者补充要求“电流感”。
3. `round3/`：短弧改为折线游走和局部分叉，使用三角折线波、非全灭的轻微电流脉动；调色对齐 V6。观察：方向正确，但电弧亮芯偏细，正常尺寸辨识弱。
4. `final/`：加粗局部电弧亮芯，降低普通直碎芒强度，收敛至 12 区电流；主轮廓仅加入低幅电流起伏。检查完整时序、深浅背景和小尺寸，主环仍近圆、窄且可读，分叉不抢主轮廓。

## 验证与局限

`final/QA/report.json` 记录主要场样本 48672 个通过，验证起止空、确定性、3 种 seed、3 个 R、边界、全关、强度 0、时长归一化与颜色隔离。
附加检查：0.20s 的独立前沿覆盖样本数相对宽环为约 0.559；这是采样面积比，不是逐像素厚度比。电弧独立可见、强度 0 为空，环宽不改变独立电弧位置。
浏览器用于检查实际 WebGL、联播、电弧分层与控件；静态证据命名 `final/QA/browser-*.png`。浅底白色电流对比偏弱，小尺寸细分叉会减少，这是当前原型的可读性边界。
没有把浏览器播放流畅度当作性能通过；Unity 实播、原生结构、批次/合批、CPU/GPU/内存及目标 PC 预算均未测。当前为作者预览，等待验收，Unity 导入仍需单独指令。
