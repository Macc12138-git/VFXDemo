# 湛蓝能量爆炸 · EnergyBurst V1

## 范围、状态与来源

作者已验收 EnergyCluster V6，要求继续制作“爆发、扩散、最后消散，范围可控”的爆炸，并明确要求两者是两个独立特效。
本次仅制作新的 EnergyBurst，保留 V6，不修改其源码、动画、贴图或播放逻辑，不添加子发射器或内部爆炸阶段。
未授权 Unity 导入；未修改 Assets、Prefab、场景或渲染设置，也没有生成 GIF。

目标平台为 PC。当前是正面 2D WebGL 制作原型，不是任意视角的真实 3D 体积爆炸；视觉与性能都须在后续授权的 Unity 适配中另验。
同时出现数量、目标 PC 型号与 CPU/GPU 帧预算尚未给定，不从浏览器流畅度推断性能达标。

独立预览：`/gallery/hd-energy-burst.html`。源码：`src/hd/energy-burst.js`；UI：`gallery/energy-burst-preview.js`。
导出/数值检查：`tools/check-energy-burst.mjs`。路径相对于 Tools/PixelFX。
选定版本为 `1.0`、数据目录 `final/`；选定 options、seed=37、源码和数据哈希见 `final/manifest.json`、`final/QA/report.json`。

本版造型与编排是新编写的程序形状，不是从参考 GIF 提取爆炸帧。
pixelfx 提供 Rng、tileFbm 基础库；观察了现有 plasma-explosion、mana-burst 的接触图与代码，参考快释放、慢衰减的编排原则，没有复制其火花、符文、雷电或像素图案。
风格参照已验收 V6 的蓝白能量、薄膜、孔洞和尖端，不读取 V6 的素材或依赖其动画。

## 分层分工

- `flash`：短促白热亮核，独立初始尺寸；快速出现并熄灭，不增加蓄力等待。
- `front`：半径随时间增长的不规则膜状前沿，角向厚薄变化和弯曲轮廓；用粗结构+侵蚀噪声逐渐打断。
- `shards`：8 片有不同朝向、偏移、卷曲和寿命的膜片，沿径向外移；膜片自身方向与移动方向分离，避免整齐的径向叶轮。
- `rays`：12 条受控外冲碎芒，早于前沿到达外侧，双端收尖、随时间减弱。没有额外随机星点、实体碎石或烟雾。
- `glow`：短暂内部蓝光和贴近膜层的少量加法光，中心先清空，再留下外围破片。

覆盖色与加法光分开计算。预览合成为 `bg*(1-alpha) + premultipliedColor + additiveLight`，最后钳制到显示范围。
同一个可见层的亮度与 Alpha 随 strength 变化；glow 单独控制加法部分。
这是作者显示 RGB 合成，不是已校准的 Unity Linear/HDR 输出或实际原生粒子结构。

没有任何新增序列帧。时间由独立特效年龄驱动，直接按任意 t 重建，支持暂停、重播、慢放和逐步检查。
默认持续 0.82 秒，`loop=false`；首端 t=0、末端 t>=duration 完全为空。
预览里的“重复预览”只在结束后额外留 0.5 秒再重播，不属于效果数据或循环发射器。

## 控制参数

| 参数 | 默认 / UI 范围 | 含义 |
| --- | --- | --- |
| radius | 180 / 90～240 逻辑 px | 主要能量的最大允许半径 R，不要求每个方向都填满 |
| duration | 0.82 / 0.4～1.4 s | 拉伸同一套归一化编排，不改变最大范围 |
| initialSize | 28 / 12～40 px | 初始亮核尺寸，不随 R 缩放 |
| strength | 1 / 0～1.5 | 主要覆盖与光强，0 时所有图层为空 |
| glow | 0.65 / 0～1.3 | 加法柔光强度，不影响主形范围或时间 |
| seed | 37 / 1～100 | 膜片朝向、到达距离、寿命等受控变化 |

覆盖色/Alpha 在 `.97R～R` 收为零；柔光最多到 `1.08R`，端点严格为空。
R 控制视觉边界，不涉及伤害检测、碰撞、对象池或宿主游戏逻辑。
较大 R 不是整个画面连同初始亮核的统一缩放：运动距离和膜层尺度随 R 调整，初始亮核、时长和亮度独立。
UI 范围以外未作为受支持输入保证，不借此声称任意无效参数都安全。

配色独立项：白热亮部 `#f8fcff`、膜面 `#235fff`、碎芒 `#75caff`、柔光 `#164bff`。
白热亮部影响亮核/膜层/膜片，膜面色影响前沿/膜片；碎芒色只影响 rays，光色只影响加法部分。
图层开关与颜色都在原型 UI 中可独立调整；不存在 V6 的联动调色或状态。

## 静态数据合同

一张 256×256 RGBA8 静态噪声，`final/Textures/EnergyBurst_Noise.png` 与 `.rgba` 原始字节对应。
R=粗结构，G=侵蚀数据；B=细噪声备用，当前公式未使用；A=255，不是透明度。
线性数据、Repeat、Bilinear、无 Mipmap；理论像素容量 262144 bytes / 256 KiB。
本阶段优先统一 RGBA8 验证，未用到的 B/A 可在后续确认实际 Unity 格式时评估双通道打包，不声称已经获得该节省。
运行预览从同一确定性函数生成一次静态字节，不逐帧更新纹理。PNG 仅为数据导出；没有从有损图像或 Canvas 预乘结果读取数据。

纹理首行对应逻辑 y 增大的图像行；WebGL 上传不翻转，在片元坐标 q 转换中翻转 Y。
每个纹理通道噪声按整数 tile 周期生成，Repeat 下双线性采样跨边界连续，不把首末 texel 相等误当唯一的无缝条件。
当前预览同时画主窗与两个小窗，存在多个 WebGL 上下文和静态纹理副本，不能据此估计未来单实例显存或 DrawCall。

## render / look / refine 记录

所有轮次保留在本目录，不覆盖旧版已验收作品。

1. `round1/`：实际查看十时刻接触图。前沿过于完整、像蓝色电圈；膜片偏窄且整齐向外，缺少破裂薄膜厚度。
2. `round2/`：打断圆周，改为粗结构与侵蚀组合；扩大并提亮膜片，增加不均匀的前沿厚度。观察：膜面出现，但膜片仍像整齐的尖叶，消散太早。
3. `round3/`：膜片减至 8 片，移动方向与自身朝向分离；适度延长后半段残片，调整破碎阈值。观察：不再是固定轮齿，破片可持续到收尾；碎芒却落在前沿内，冲击力不足。
4. `final/`：碎芒速度领先前沿，并改双端收尖；加大主轮廓不均匀度，主覆盖限制到 R、柔光到 1.08R。补充初始亮核独立性检查，避免最小 R 暗中缩小亮核；小窗缩放为 .35/.175，最大 R 时仍留边。

实际查看最终 contact、background-scale、radius、layers 及浏览器 WebGL 画面。
当前膜片仍属于解析程序造型，部分细边比较干净；这是新爆炸的试作，不声称具有参考逐帧原稿完全相同的手绘笔触。
浅色底上的白热碎芒较弱，不能用深底效果保证所有底色都有同样对比度。
