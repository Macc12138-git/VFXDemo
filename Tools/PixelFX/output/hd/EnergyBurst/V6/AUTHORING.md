## 本次设计与不变量

作者希望保留能量环内的白色高亮，重做扩散雾气，并参考初始能量球的跳动。
这里不是给整圈做同步缩放，而是在不同角度错开鼓起、回卷和退去。

1. V5 白色折叠亮部、聚集、爆发白芯的形状和时序保留；原有电流路径保持原样。
2. 蓝色层从连续硬边圆环改为两道有前后关系的能量片层。主轮廓仍近圆形。
3. 静态噪声沿径向向外流动，叠加局部扭曲、错相鼓动、蓝色卷边与密度变化。
4. 前沿与后随片层在后半段仍继续外移，并收窄、变薄、消散。新增亮部保持蓝色，不添加白色花纹。
5. `mistColor` 只改变新蓝色层；共享 `bodyColor` 同时参与原高亮的冷色过渡，页面已说明这一点。
6. 可调范围控制视觉，未包含伤害判定或游戏逻辑。

## 表达与资源

- 延用 V5 的一张 128×128 RGBA 静态噪声数据，线性插值、Repeat，无 Mipmap，数据非 sRGB 色图。
- 没有新增位图、序列帧或图集。QA PNG 仅用于审稿，不是运行资源。
- CPU 作者场与 WebGL 材质使用相同公式；颜色覆盖采用显示 RGB 的预乘覆盖，光晕为独立加法。
- 白色保留层先应用自身边界，再覆盖在新蓝色层上，避免叠加造成新层双重裁切。
- 时钟使用本效果年龄，`t = age * 1.02 / duration`；范围保持比例缩放。
- 此网页不是 Unity Shader，不证明 Unity/Metal 编译、线性光空间外观或 PC 运行性能。

## 三轮 render / look / refine

### Round 1

文件：`round1/QA/`，源码 hash `aa6a5a6c7ef94072eea4351fcbfeadae01f83f6fcb377278092599c96177c9de`。

重做局部鼓动、前沿与后随层、向外流动噪声及密度消散。静态与动态对照可见旧硬边被打散，
但蓝色较暗、细碎侵蚀偏多，像烟而非能量。

### Round 2

文件：`round2/QA/`，源码 hash `7ebae9e84f334c8e78e230462bd1f161d324e6aa5b7e1538c6a8b621e1aa14cf`。

降低空间噪声频率，减少细通道权重与碎孔，提高选择性的亮蓝卷边，改为更大的四/七瓣错相起伏。
对照图及慢放中，翻卷结构更清楚。剩余问题是后半段仍容易停成一圈薄烟。

### Round 3 / final

文件：`round3/QA/`、`final/QA/`，最终源码 hash 见上。

增加后半段前沿与后随层的径向外移，同时渐窄；让 pulse=0 不再保留该层的宽度及亮度鼓动。
校正 CPU/WebGL 的覆盖顺序和边界。预览中核对默认/慢放、独立蓝色层、白色保留层、
R90/R220、浅色和棋盘底、0.55/1.5 秒时长及最终空帧。最终默认恢复全部图层、R180、1.02 秒、1×播放。
