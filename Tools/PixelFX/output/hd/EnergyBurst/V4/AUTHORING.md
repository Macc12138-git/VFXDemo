# EnergyBurst V4 — 电流能量爆炸重设计

日期：2026-11-08。当前是作者审阅稿，等待视觉验收；未导入 Unity。

## 本次方向

按作者要求摒弃现有圆环/膜片方案。以电流路径本身构成爆炸主体：蓝色能量向中心聚集、变为白热亮核，随后向外击穿为有粗细变化的折转分叉电流。第二波短电流沿展开的路径向外窜流并再分叉，最后断开、变细、消失。

不使用闭合圆周、环带、膜面碎片、烟火爆炸或全屏闪白。配色沿用能量团的湛蓝、白热与局部蓝光；V6 原稿及 V1–V3 爆炸保留不变。

## 默认参数及时间

源码：`Tools/PixelFX/src/hd/energy-burst-v4.js`。

SHA256：`ca499c6ab4e2e39b8f07cf7c0566824962c2c0ae052b7c15203e658092ef5308`。

默认 seed=37，R=180 逻辑 px，总时长 0.96s，聚集参考时长 0.15s，intensity=1，flow=1，glow=0.65。白热 `#ffffff`、主蓝 `#2458ff`、亮边 `#adcaff`、蓝光 `#1440ff`，均可独立调整。

默认节奏：

- 0–0.15s：局部蓝色能量收束、白热亮核增强，短电流向内聚集。
- 约 0.15–0.24s：白热短闪，首批粗电流迅速向外击穿。
- 约 0.18–0.40s：不等长的主路径和次级分叉展开，亮包沿路径外移。
- 约 0.27–0.84s：独立短电流沿原扩散路线再次窜流、向两侧分叉；主路径提前断开以让窜流可读。
- 尾段电流破碎变细；t=0.96s 严格为空。

总时长按归一化年龄缩放所有阶段；聚集时长单位为 0.96s 基准下的秒数。R 同时缩放路径、亮核及粗细，控制视觉最大范围，不包含伤害判定。预览可调 R=90–240px、duration=0.48–1.4s、charge=0.08–0.22 参考秒。

保持不变：先收束后释放、蓝白明暗层次、粗主电流/细分叉层级、向外传导和无残留收尾。允许受 seed 控制的变化：方向、长短、弯折、宽度、出生时差、次级电流路线。页面的固定 seed 便于审稿，不要求未来 Unity 对每根路径逐一映射节点。

## Render / look / refine

1. `round1`：初稿具有聚集、八条主路径、分叉和二次窜流。接触图显示路径过于均匀、细线与蓝边接近管线，爆炸主体偏单薄。
2. `round2`：增大主路径弯折差异，加入沿电流扩散的局部开放卷曲，改为逐段粗细变化，增大聚集体积。观察发现某些卷曲过密、分叉成团，亮部仍偏细。
3. `round3`：卷曲缩短为开放短折转，提高白热比例、降低亮边的青色倾向；聚集与爆发亮核增强。接触图和背景检查中细电流可读，但主形仍不够有重量。
4. `round4`：加厚主放电、调整弯折范围并强化前行亮包。动态分层检查发现主路径残留会遮盖后续窜流。
5. `final`：主路径更早断开和衰减，二次电流加粗、提亮并稍延后出生，分离“首波击穿”和“路径再放电”的节奏。重新渲染及动态检查。

各轮保留接触图、源码快照、默认参数与 hash；最终快照见 `final/QA/energy-burst-v4.source.js`。
