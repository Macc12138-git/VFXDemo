# EnergyCluster V5 · 球面流动膜试作

## 范围与状态

作者指令：“第一种方式尝试制作”。承接的方案是球面膜 Shader：设计的结构遮罩 + Flow Map + 局部溶解。
目标 PC；本次仅制作与预览，不是导入授权。没有写入 Unity Assets、Prefab 或工作场景，也没有生成新 GIF。
旧版本及作者原 GIF 保留。本版新建曲线结构，不抽取、播放参考帧，也不把程序曲线称为实际手绘素材。

入口：`/gallery/hd-energy-cluster-v5.html`。源码：`src/hd/energy-cluster-v5.js`。
默认版本、seed=37、options、源码 SHA256、数据格式以同目录 `manifest.json` 为准。

## 分层与实现

- 主膜：真实 UV 球面网格，64×32 分段，2145 个顶点；每个膜面 Pass 提交 4096 个三角形，由剔除保留对应半面。
- 造型：有粗细变化的 S 曲线、斜向连接、开口环、钩形和孔洞；B 通道保留边界到膜内的灰度变化。
- 流动：RG 流向数据 + 两相 UV 输运；局部扰动减小后保留形状，主流向推进仍存在。
- 溶解：A 通道控制局部边缘偏移，阈值逐渐侵蚀；不是用随机噪声决定主轮廓。
- 厚度感：前膜明亮、后膜偏暗；亮膜边缘接近白色，宽膜内部偏蓝。无永久 Fresnel 圆环。
- 体积/亮核/光晕：实时径向色带及解析形状，不存储动画贴图。
- 球面形变：GPU 径向顶点波动；当前着色用原球面法线近似，没有计算形变后的真实几何法线。

绘制顺序为背景/光晕 → 后膜 → 体积/亮核 → 前膜；预乘输出搭配 ONE / ONE_MINUS_SRC_ALPHA。
这是无场景深度的正交作者预览，未验证 Unity 的透视、场景深度穿插与透明排序。

完整流动循环 **2.4 秒**；两相局部扰动周期 **0.48 秒**。2.4 秒是本次制作的循环选择，不是粒子寿命。
此前缩短序列帧是为了图集大小；静态图方案的循环加长不增加贴图容量。
流动强度为局部扰动幅度，不是整体播放速度；要完全冻结须暂停时间。

## 素材合同与资源取舍

单张 256×256 RGBA8 静态数据图：R/G=UV 流向，B=膜结构，A=边缘侵蚀数据。
线性数据、Repeat、Bilinear、无 Mipmap；A **不是透明度**，不得预乘或经 Canvas 图片解码再作为数据使用。
PNG 与 `.rgba` 原始字节一并保存；浏览器由同一函数生成原始字节上传，未逐帧更新纹理。
U 为球面 azimuth，V 从北极 0 到南极 1；PNG 首行为 V=0，原始 WebGL 上传不翻转 Y。

RGBA8 无 Mipmap 理论像素容量为 **262144 bytes / 0.25 MiB**。
比 V4.3 R8 图集理论 1.25 MiB 小，但本版 PNG 约 214 KiB，反而大于旧壳图集约 77.5 KiB；磁盘压缩大小不能代替 GPU 内存。
本版增加网格与多次纹理采样，不因贴图更小或运动连续就宣称性能更好。Unity 格式、批次、CPU/GPU、Player 和目标 PC 预算均未测。

## render / look / refine 记录

每轮有独立源码快照、CPU 接触图、背景/尺寸图及数据检查，位于 `QA/roundN/`；WebGL 截图是几何与剔除的主要视觉证据。

1. **Round 1**：看组合、纯壳层与八个时刻。问题：孤立平滑丝带偏多，灰白表面像不发光的薄片，前后连接少。
2. **Round 2**：加宽主膜，增加下方连接弧与孔洞，降低两相扭动幅度，增加有限破边、前膜亮度及后膜可见度。观察：连接改善，但大块白面过实、横向带感明显。
3. **Round 3**：添加细长开孔；将着色改为亮边/偏蓝膜面，减少膜内部加法泛白。观察：明暗改善，但结构数据平台区仍导致宽处偏平。
4. **Round 4**：主连接改斜向；结构数据保留横截面灰度，宽膜中部进一步降为蓝色；修正 UV 接缝处斜向曲线门控，使溶解阈值更充分侵蚀，并避免阈值端点的反向 smoothstep。观察：膜内层次和连续弯曲更清楚，56px 下主体仍能辨认；自由断裂和向外甩出的细尖角仍弱于参考。

这是一种新表现路径的试作，不是“原 GIF 质感已完全复现”。固定遮罩在循环中会保留可辨识的形状，拓扑变化主要来自输运与侵蚀。

## 验证结果与边界

`QA/final/report.json`：CPU 参考测试通过。包括确定性、精确完整循环、U 接缝、溶解=1 清除膜、参数端点数值有限、关闭所有图层为空、后膜关闭时换色无影响、索引范围。
检查脚本还覆盖 width/dissolve 组合端点，PNG 解压后与原始 RGBA 的 65536 个 texel 字节完全一致。
CPU 图像用迭代球面求交近似 GPU 网格，并非逐像素一致；浏览器实际 WebGL 编译与画面另验。

浏览器已实查：

- 默认组合与纯壳层；前膜、后膜独立显示和全部关闭。
- 前膜跨色相改色、后膜单独改色，恢复默认后复核。
- 溶解=0/1；1 时纯壳层为空，亮核/体积仍保留。
- 最大起伏、水平/俯仰极限角，未见极区爆裂或剔除翻面。
- 深色、浅色与棋盘背景；112px、56px 原尺寸小窗。
- 末端 2.3999s 与首端 0s 视觉对照；正常/0.25×播放、暂停、时间轴、重播。
- 最终检查未捕获浏览器 warning/error；这不构成 Unity/目标 PC 性能验收。

后续应先由作者判断壳层风格是否值得继续；未获得新的明确指令前不导入 Unity。
