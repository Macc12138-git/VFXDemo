## 来源与设计取舍

源自作者上传的 `codex-clipboard-5032fe0e-6c69-4a34-aec3-1bf80ddefba3.gif`；工程保留副本为 `V2/Reference-original.gif`。
实际读取 V3 的 20 张 512px 透明帧，使用统一裁切 `(80,80,432,432)`，再缩到 256px，不逐帧改变中心。
这是参考衍生的近似拆层，不是新绘制动画，也不是取得原作者的分层源文件；参考的商用授权未核验。

V4.3 的二值轮廓/SDF 丢失了灰阶、薄边和细尖角；V5 的静态图球面输运又变成了平滑丝带。
V6 保留复杂拓扑变化在壳层帧中，不再生成距离场或旋转固定图案；连续灰阶描述膜面明暗，连续 Alpha 描述软边与透明度。
尖角、连接和游离小片均来自壳层帧，不额外添加随机闪电或装饰粒子。

## 分层与数据合同

- 壳层：20 帧，单帧 256×256，5×4 图集 1280×1024。PNG 为 LA，L=直通灰阶，A=透明度；raw `.rg` 为逐 texel 两字节同序数据，不是 RGBA 图片。
- 核心、体积和光晕：`EnergyCluster_Profiles.rgba`，256×3、共 3072 bytes 的静态径向数据，没有时间帧。
- profile 第 0 行：体积，预乘的显示 RGB + 透明度；第 1 行：加法光晕 RGB、A=0；第 2 行：核心遮罩重复存入 RGBA。
- 灰阶/遮罩不经硬件 sRGB 解码。profile RGB 当前是作者预览显示色值，不是已校准的 Unity 线性/HDR 输出。
- Bilinear / Clamp / 无 Mipmap；PNG/raw 首行对应逻辑上方。WebGL 不翻转上传数据，在片元坐标转换中翻转 Y。
- 逻辑帧范围 ±128，中心锚点 `(0.5,0.5)`；核心中心 `(0,-2.5454545)`。profile 半径按原 512px 坐标采样，`r=length(q+(0,2.5454545))*352/256`，采样坐标为 `r-.5`。
- profile 末端 238～254 原图像素渐隐为零，超过范围不得夹持到非零色值，避免污染整张背景。
- 不得用 Canvas 图片解码读取数据通道：其透明像素预乘会改变 LA 或 profile 数据。运行预览直接读取 raw 字节。

合成顺序：背景 → 体积 → 加法光晕 → 核心 → 紧贴壳层的少量加法光 → 壳层覆盖。
相邻帧先分别计算预乘 RGB/Alpha，再插值；不先混直通灰阶与 Alpha 后相乘。
默认 `short`：前 75% 帧时段保持造型，最后 25% 做 smoothstep 过渡；`alpha` 全时段混帧；`step` 完全保持。
短过渡减少双轮廓共存时间，但没有生成真实中间造型或使用光流。慢放仍能看出离散动作，不能宣称完全连续。
参考窗口始终逐帧显示；过渡时左侧可能包含下一帧，不能把该时刻视作逐像素同姿态比较。

默认 0.48 秒循环，20/.48≈41.667 个形状/秒；参考原周期为 0.8 秒/25fps。
“参考节奏”将速度设为 .6，恢复原动作节奏；这不是增删帧。默认强度均为 1，壳层透明度 1。
独立颜色：壳层亮部 `#ffffff`、暗部 `#0073ff`、亮核 `#fbfcff`、内光 `#45b5ff`、体积 `#2458ff`、光晕 `#1440ff`。

## 实际迭代记录

各轮有独立导出、接触图及对照图；完成目录不覆盖。

1. `round1/`：恢复了参考钩形、孔洞和细尖角；纯壳层中仍有核心圆边与大面积弱对比体积残留，静态底层有不应常驻的亮环。
2. `round2/`：径向色带改为单调衰减，去掉常驻亮环；用强信号的柔软邻域限制弱残留，但最终轮廓仍保留连续灰阶/Alpha。核心边缘经参考校准后仍有细圈。
3. `round3/`：限制核心区正对比残留，用核心遮罩支持负对比遮挡；核心圆圈明显减少。加四个对角偏移的低强度壳层贴光，避免靠大光晕掩盖形状。
4. `final/`：径向 profile 统一扩至源半径 256，末端淡出为零，修复非零边值污染背景的问题；收紧核心支持范围。实际查看最终 CPU 和浏览器同帧对照，主体轮廓比 V5 接近参考。

仍存在：拆层估算导致核心附近的细弧/遮挡斑，调色为蓝白重建而非原 RGB；背景环纹与细微体积变化未逐帧保留。
纯壳层不等于完全无核心信息，尤其负对比遮挡仍受源亮核形状影响。不将这些缺口称为完全复现。
