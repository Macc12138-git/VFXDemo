# EnergyCluster V4.3 · 混合分层原型

作者本次要求：区分必须用帧动画的部分与可以实时实现的部分，兼顾贴图资源和流畅度。
没有新的 Unity 导入授权。本版只在 Assets 外制作与浏览器预览，旧版与 Unity 场景均不修改。

## 选定方案

| 部分 | 选定表达 | 保留与限制 |
| --- | --- | --- |
| 白色翻卷壳、孔洞和相连的锯齿尖角 | 20 张 256×256 单通道 SDF 形状帧，连续时间插值 | 保留参考的关键造型变化。不是旋转静态环，也不是把整团画面转成新序列。 |
| 白热圆核 | 实时解析圆形，极小连续脉动 | 不再在每张贴图内存相同白点。 |
| 蓝色体积与青色内光 | 解析径向色带和连续运动光团 | 颜色、体积、内光可分开调；不是原图逐像素还原。 |
| 近身光晕 | 独立的实时低强度加法光 | 不用真实 Light，不依赖额外 Bloom 设置。 |
| 独立细碎芒 | 少量短寿命折线粒子，连续位置/透明度 | 无序列贴图。当前是原生粒子思路的 Canvas 模拟，不是 Unity 原生运行证据。 |

原始输入是作者提供的 GIF 转制帧，没有原画分层文件。壳层通过亮度、中心区域与连通形状
近似拆出，不能宣称真正分离了原作者图层；与主壳相连的尖角仍在动画层中。
默认配色遵循原参考蓝白关系，但实时体积与碎芒是重建，不是原图等价重合成。

## 不是继续削减动作帧

- V3.2：12 张整效果 RGBA 帧，25 FPS / 0.48s。
- V4.3：恢复原参考全部 20 张关键形，单帧仍为 256，循环仍为 0.48s。
- 壳层采样频率约 41.667 FPS，每个渲染时刻采样相邻两张距离场并插值后重建轮廓；
  亮核、体积、光晕和碎芒不被帧格时钟量化。不是承诺浏览器或目标游戏恒定 60 FPS。
- 插值不是简单 Alpha 叠加，可减少两套白壳的重影；也不是光流或真正绘制中间帧，
  新孔洞/消失细带仍可能收缩。需作者动态验收，不能用连续性测试替代观感。
- 所有层使用单实例秒数；当前预览支持暂停、重播、慢放与跨循环。未来 Unity 应由
  原生粒子年龄/顶点流承载时钟，不能用全局 `_Time` 假装逐实例可暂停。

## 资源合同

- `Textures/EnergyCluster_ShellSDF.png`：灰度 L，1280×1024，5 列×4 行；左到右、上到下。
- 数据用途，sRGB 必须关闭；R 解码为 `(R*2-1)*10` 个原始 256 单帧像素，内部为正。
- 以 R8 UNorm 保存，Bilinear / Clamp / 无 Mipmap；单格采样限制在半 texel 边界内。
- 固定 pivot=(.5,.5)，不逐帧裁切、重定位或缩放。源码默认 seed=37。
- PNG 79,405 字节（77.5 KiB），相对旧整帧图集 577,139 字节减少约 86.24%。
- 旧 12 帧 RGBA8 无 Mipmap 理论像素容量 3 MiB；新 20 帧 R8 为 1.25 MiB，减少 58.33%。
  R8 格式必须在真正导入时核验。如果回退为 RGBA8，新图会是 5 MiB，反而超过基线。
- 只比较纹理容量，不代表总显存。预览中有对照纹理、CPU 解码副本和额外渲染表面，不能
  当成游戏运行资源预算；两次纹理采样和解析运算也有 GPU 成本，尚未在 Unity/Player 实测。
- 最终版不依赖低分辨率运动图。失败光流试作及中间版本保留在相邻 V4、V4.2 目录中。

## 三轮观察与取舍

1. `V4/QA/round1`：12 张轮廓直接插值。连续性测试通过，但中间帧可见部分细长内带缩没，
   只减少停帧不等于保住质感。保留该轮源码 hash 与接触表。
2. `V4/QA/flow-midpoints.png`：尝试 64px 双向运动补偿。局部对齐误差下降，但中间轮廓
   破坏明显，证明误差指标不足以替代视觉。放弃该运行方案。
   `V4.2/QA/round2` 随后改为恢复 20 张形状，移除运动纹理，减弱紧贴壳层的蓝光，
   并清除距离场截断值带来的远处恒定微光。
3. `V4.3/QA/round3`：缩小中心剔除半径（17→11.5px），保留靠近亮核的翻卷带；亮核先于
   白壳合成，保留壳层前景关系。复查全部 20 个半帧、纯黑/参考底/浅色/棋盘底及
   256/128/64 单帧显示尺寸；加入独立颜色和光晕开关测试。
