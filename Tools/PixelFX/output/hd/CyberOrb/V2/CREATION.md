# CyberOrb V2 · 白热核心短尾能量弹

状态：Canvas 制作原稿，等待作者视觉验收；没有导入 Unity。

## 作者方向与边界

- 使用第二份 GIF 正中央的白色亮点作为本体，不采用外围大电环。
- 用于高速、高频、消耗型子弹：只保留圆形热芯、紧凑蓝青微光、单条短尾。
- 不加入数字碎光、旋转框、额外电弧、武器、人物、命中或伤害逻辑。
- 依 vfxdemo-pixelfx 制作流程；V1 源码和页面保留，不覆盖旧稿。
- 参考输入为作者提供的 GIF，归档为 reference-input.gif；不是本轮生成的动画。

## 三轮观察与修订

1. V2.0.0：在实时预览检查单发和 16 发/秒。圆形白热核心和短尾已取代 V1 的蓝球、电离环与装饰碎光；观察到包光略偏浅青，核心硬描边仍比较显眼。
2. V2.0.1：改为更冷的蓝青配色，并提高外层蓝色微光相对权重。检查单发静态图；继续收敛硬青色描边，避免又读成带边框的球。
3. V2.0.2：本体改成白热圆芯的柔和收边，不画外圈线条。实看浅色背景、64 发/秒的慢放、透明棋盘上的独立本体，以及恢复后的深色底 16 发/秒。保留单短尾，不再添加样式。
