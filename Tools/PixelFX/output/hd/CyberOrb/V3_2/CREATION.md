## 分层与运动

一层小范围径向柔光以 additive 绘制在弹体后方，再复用 V3.1 的白芯、单圈描边、单条短尾。柔光颜色与描边颜色共用，但强度、范围与开关独立可调。圆形轮廓、4 秒循环与基线轻微尺寸呼吸不变；没有新的独立闪烁或形变。

命中直接复用基线 one-shot，弹体/描边/柔光在命中时消失，残尾与 .2 秒命中收尾保持不变。高频射击只是原尺寸可读性/重叠探查，不是性能验证。Canvas 透明画布与不透明背景的合成、Unity 线性光与 Bloom 条件并不等价，不能直接当成 Unity 最终视觉。

## Render / look / refine

1. `3.2.0` / round1：浅蓝 `#8edbff`，光晕 .6、外半径 1.5R。观察深浅/暖/棋盘底及直径 12px 的弹体。颜色已柔和，但放大轮廓的光晕偏宽，浅底边缘偏亮。
2. `3.2.1` / round2：改为更浅的 `#9edfff`，光晕 .55、外半径收至 1.35R。仍保留白热中心与单圈描边；小尺寸能辨认，光晕不再明显膨胀。外围低 Alpha 肩部仍可更轻。
3. `3.2.2` / final：只降低柔光外围渐变的低 Alpha 肩部，进一步收紧视觉范围，不削弱中心。复看四种底色、首尾、游戏尺寸；实时页面检查浅底 64 发/秒、独立开关与强度/范围控制，恢复深色底、16 发/秒与默认参数。

图像与采样按 round1/round2/final 留在本目录；最终页面静态证据 `preview-ui.png`。无序列帧运行资源。
