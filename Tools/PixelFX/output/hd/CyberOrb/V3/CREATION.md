状态：pixelfx 高清 Canvas 制作预览，等待作者验收。没有导入 Unity。

## 作者要求

去掉 V2 外围光晕；让单条短拖尾更明显；新增击中效果。
沿用上一轮的中心白热圆点本体及高速、高频消耗型子弹定位，不加长、多股尾迹或大范围装饰。
按 vfxdemo-pixelfx 的制作阶段执行，保留 V1 / V2；不创建或修改 Unity 资源。

- core=#f4feff；rim=#65e5ff；trail=#2674ff。
- 主体保持圆形白热亮点。单条蓝青尾迹通过增加宽度和不透明度提高辨识度，不依赖外围加法光晕。
- 飞行效果只有尾迹和本体两次 Canvas 形状填充；此数不是 Unity Draw Calls。
- 命中是独立 0.2 秒 one-shot：白芯/蓝边短闪、最多四枚短碎芒；无烟、无扩散环、无柔光球。
- 接触后本体消失；残尾在 35ms 内收缩、淡出；85ms 内闪点消退，碎芒在 0.2 秒前完全消失。
- 上方特写为 3×；右侧命中定位虚线和中间分隔线属于 UI 辅助，不在效果源码里。
- 下方连发为直径 12px 的逻辑画布尺寸、默认 16 发/秒，所有子弹命中同一点以便观察重叠；不是实际业务预算。

## 三轮观察和实际修订

1. V3.0.0：实时页面与静态设计/命中 contact 图检查。外围光晕已移除；短尾宽度和 Alpha 明显增加。观察到命中残尾有平切端，碎芒后半段偏弱。
2. V3.0.1：残尾改为向接触点收缩并淡出；四枚短碎芒略增宽、增长；闪点延至 85ms 内收尾。补右侧视窗裁切，避免高速入画时尾迹越过分隔线。浅色底检查发现命中末段对比不足。
3. V3.0.2：闪点外层改为紧凑蓝色边缘，碎芒蓝到青渐变，略减缓碎芒透明度衰减；没有增加光晕或装饰层。复看浅色底 64 发/秒重叠、棋盘底独立白点和完全消散，再恢复深色底默认连发。
