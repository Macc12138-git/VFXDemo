# 雷霆环爆 V1 · 制作记录

作者授权：2026-11-05「开始制作」。仅制作/预览，未授权导入 Unity。

- 来源：作者提供的 600×300 / 26 帧 / 1.10 s GIF。只分析特效，不复制人物、武器、场景。
- 标识：`hd/lightning-nova`。主源码 `src/hd/lightning-nova.js`，预览 `gallery/hd-lightning-nova.html`。
- 一句话：白热落雷击中中心，青蓝尖刺炸开，断裂长电光带沿地面向外甩出，补闪与残余电弧收尾。
- 默认 seed=69，radius=2.5，intensity=1，glow=0.65，density=1；四项默认配色见源码 meta.options。
- 1.20 s 单次效果，循环播放器额外留白 0.70 s；0.10 s 命中，0.15–0.48 s 范围扩散，0.355/0.49 s 补闪，1.10 s 之前清空可见余韵。
- 2D：固定 24° 正交构图；3D：透视世界空间 XZ 圆形带、Y 向主雷与立体细电弧，可旋转缩放。
- 表达：实时解析几何、顶点颜色和独立加法光；无外部贴图、无帧动画、无角色。两版共享艺术时钟和参数。
- 原生 Unity 组件映射尚未实施；浏览器的几何重建不代表已证明无脚本原生粒子迁移可行。

## Render / Look / Refine

1. 轮廓/节奏：动态播放及 0.205 s 定格观察。外围太细，像断续细电线；加宽电光带、强化主雷热芯、增大尖刺宽度。
2. 内部/次级：检查爆发与 0.320 s 俯视。周期起伏造成波浪/褶边感；去除高频外轮廓波浪，改为长弧与不均匀内侧切口，调整为更少、更长的主笔触，加快扩散。
3. 构图/合成：全画面与默认镜头检查。修正透明 Canvas 双重 Alpha，使用预乘片元与匹配 Blend；加大上边界余量，扩大断口、增加切向碎光，并提前次级电弧出现时间。

艺术不变量：主落雷焦点、青蓝白三层、分段圆形扩散、短促补闪、结束清空。
允许变化：电弧路径、笔触长度/宽度、碎光出生/尺寸/速度/寿命，不改变主节奏与范围。
