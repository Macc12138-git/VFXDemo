# 雷霆环爆 V1.2 · 空间细电弧审稿版

状态：pixelfx WebGL 几何制作预览，等待作者视觉验收；未获导入授权，未修改 Unity 资产。

## 表达与三轮观察

1. `01-spatial-draft.jpg`：用窄菱形截面电弧取代径向宽带，五条开放倾斜弧与两条内侧甩光形成高低层。
   实看问题：白热面被自身后画的面盖住，轮廓偏细线画圆，内侧层次不够明确。
2. `02-wrap-forks.jpg`：单壳电弧改用逐面远近排序，增加稀疏折返、短分叉与逆向扫动；暖底检查。
   实看问题：两条内侧电弧仍像从中心伸出的平面辐条；浅底白线对比也不足。
3. `03-descending-wrap.jpg`：内侧改成半径渐增、高度渐降的开放螺旋，单条轨迹可经过中心前后；外圈长度非对称，保留缺口。
   `04-low.jpg` / `05-top.jpg` 检查低视角高低交错与俯视范围。随后 `06-light.jpg` 暴露浅底白轮廓偏弱，
   追加窄蓝缘到白热脊的截面配色，得到 `07-final-light.jpg`。`08-spread.jpg` / `09-checker.jpg` 检查扩散与透明边缘。

宽度没有通过放大光晕补回。默认 seed=69 在 t=.24 的最大截面直径约 .0704 世界单位；
三 seed / 全时间采样最大直径约 .0821。高度随轨迹变化，三 seed 的峰值高度约 1.58；不是全部贴地，也不是完整球壳。

## 实现与边界

- 主落雷、尖刺、次级电弧、飞散碎光、地面光晕的几何与 V1.1 保持一致，24 个关闭 rings 的 hash 回归通过。
- 颜色层使用相机空间远到近的笔触/小面片排序，复合落雷通道保留相同锚点下的蓝/青/白内部顺序。
  这是效果内透明画笔排序，不是场景深度缓冲方案，也不代表已验证与 Unity 场景物体的深度交互。
- 颜色：预乘 Alpha；光晕：独立 Additive；无全局 Bloom、无整效果序列帧、无新增 GIF。
- 2D 使用固定正交构图；3D 使用相同世界几何、透视和可调视角，均不是 Unity 实际运行版本。
