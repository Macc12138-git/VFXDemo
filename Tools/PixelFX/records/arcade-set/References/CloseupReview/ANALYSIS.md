# 作者单枚截图与 V3 对照

本次仅检查参考和保存静态诊断图，没有修改特效源码、预览、爆炸或 Unity 资产。
截图源为作者本轮提供的 PNG（50×154）；包含缩放/过滤后的过渡色，不把全部采样颜色当原始像素调色板。

`reference-vs-current.png` 左为作者截图中的主体区域，右为 V3 第三个热芯姿态。
按整个火球高度对齐，不代表相同时间点或相同原始像素尺寸。

确定的偏差：

1. 参考橙红主体上圆下收、纵向饱满，不能抽象为规则圆盘接独立的细长三角尾。
   V3 的圆头和尾锥接缝明显，主体下半部形体层次不足。
2. 参考紫焰包住橙红主体下缘，紫色带有厚度、分层和钝收口；V3 过于笔直、尖细、几何化。
   左右最外侧的橙紫竖片是邻弹干扰，不能并入单枚尾焰。
3. 作者截图为偏黄绿的不规则热芯、暖粉橙主体、砖红暗部、亮紫/深紫尾部。
   V3 暗相热芯趋同于橙色外壳，亮相又偏乳白；明暗关系和色相分层没有对上。
4. F030–F035 同一枚火球的连续参考中，热芯亮区的面积、内部缺口和色块分布发生变化。
   V3 仅对固定热芯多边形的颜色值做插值，不能代表这些内部形状变化。
5. “尾炎变化不明显”不能直接作为“尾炎/轮廓逐像素冻结”的艺术合同。
   V3 的固定 mask / tail 检查只证明实现满足了自行制定的条件，不证明视觉复现正确。

`F030-F035-aligned-reference.png` 对先前跟踪的中间一枚做上部暖色头定位，连续逐帧展示。
画面仍保留真实邻弹遮挡，因此不能当作已分离的干净序列帧素材。
自动头部匹配结果只找出了多个相似实例；未确认作者截图对应唯一 GIF 帧和实例，候选图不作归属证据。

修正顺序应为：橙红主形及紫焰包覆关系 → 色阶/热芯结构 → 对齐后的逐帧变化；
不是继续在 V3 圆头加尖锥的几何结构上调整亮度或速度。暂不改爆炸，避免同时扩散两项误差。
