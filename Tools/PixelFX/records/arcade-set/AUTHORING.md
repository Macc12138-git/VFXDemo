## 这次实际重画的内容

- 连贯的上圆下收橙红体积，扩宽中段，不再是圆盘与尖锥的拼接；下半部阴影沿圆弧收口。
- 短厚紫焰包覆主体下缘，分出暗紫、紫红和较亮紫色带，钝收口；没有齐射侧弹或游离火舌。
- 暗相保持黄绿热芯，亮相扩大浅黄亮区。六个热区边界和内部缺口不同，不再仅对固定图案调亮度。
- 尾部只作极小色带变化：相邻姿态 0–2 个尾区像素变化，相比热芯 17–74 个像素变化更安静。
  不把“变化不明显”当成必须冻结每个像素的合同。
- 图形为独立代码构形；截图和 GIF 裁图仅在审稿页展示，不作为效果运行素材，也不制作贴图动画。

## 当前源码、参数与快照

源码：`src/fx/fire/arcade-fireball.js`；36×48 画布，锚点 [18,19]，50 fps，六姿态 0.12 s 循环。
默认 seed 17、pulse 1；shell `palette`、`tailPalette`、`heatPalette` 三套语义色阶分别可调。

## 四轮观察与修改

1. `fireball-v4/round1`：重建连贯橙红体、包覆紫焰、六个热区轮廓。
   并排发现热芯过小、暗相赭黄过多，主体下方有不自然的平切阴影。
2. `fireball-v4/round2`：扩大热区、加强黄绿色，改为圆弧收口，降低“金属弹壳”式长高光。
   发现热芯缺口过大、亮相靠近前缘时有穿出主形的风险。
3. `fireball-v4/round3`：缩小缺口、保持暗相绿色、限定热区在主体内，添加少量连贯阴影转折。
   检查所有姿态与三种底色；随后对真实浏览器尺寸发现主体仍偏瘦。
4. `fireball-v4/round4`：扩宽橙红中段和热区，保持短厚紫焰；最终作为 `final` 锁定。
   当前热区覆盖 66–87 像素，暗相无浅黄高亮像素，亮相有 28–39 个高亮像素。
   数字只描述图形变化，不能代替作者视觉验收或与原 GIF 的精确相似度证明。

# V3 历史 · 单枚大火球与爆炸

## 当前制作稿

本轮只制作一枚大火球及其一次性爆炸。飞行器、喷气、小型弹药均不在当前预览中，旧文件保留。

预览：`/gallery/pixel-arcade.html`。默认单枚火球循环，点击“播放完整过程”显示
同一枚火球向上飞行并在终点替换为爆炸，结束后清空停止。另可单独查看八帧爆炸。
暂停、逐帧、¼/½ 速、核心明暗开关、2/4/6 倍及四种底色均在页面中。

## 参考判断与不确定性

参考帧采用一基计数，F030 即 GIF 索引 29。跟踪 F030 下方三连火球中的中间一枚，
而不是把多枚叠加当作主体轮廓。静态跟踪证据在 `References/FlightImpact/`。

- F030–F041 的连续样本显示：圆形头部热芯明暗约六个 GIF 帧重复；外围与紫红锥尾变化很小。
- GIF 每帧为 20 ms，本稿六姿态循环为 0.12 s。修正了前期试稿 25 fps 的偏慢判断。
- 约 F050 目标火球消失并出现小乳白闪点；后续命中区域出现膨胀白团与橙褐卷云。
  敌机受击闪白、圆环串、竖向光束及邻弹命中相互遮挡，不能精确归属全部像素。
- 本稿按“爆闪 → 膨胀 → 冷却卷云 → 破碎清空”做八个几何姿态，暂用 0.16 s。
  后段是排除干扰后的补绘解释，不宣称已分离出原游戏的完整火球爆炸动画。
  后续由作者重点确认：膨胀白团/卷云是否属于其想要的爆炸，而不是敌机死亡表现。

## 当前源码与版本

## V2 三轮观察与修改

1. `pulse-round1`：冻结轮廓，加入整体亮暗脉动并撤下飞行器。
   深浅底对照发现暗相过紫、接近熄灭；亮/暗平均像素亮度比约 2.08。
2. `pulse-round2`：减弱冷却幅度，暗相保留红橙热芯；修正审稿相位图标签位置。
   亮暗比约 1.60，暗相仍有外缘融入深底、看起来收缩的问题。
3. `pulse-round3`：降低外轮廓暗色带的变暗幅度，主体热芯继续明暗交替。
   最终亮暗比约 1.51；像素覆盖形状逐帧完全一致。检查实际尺寸、深浅底与循环。

静态相位对照图中的 BRIGHT / DIM 是同一个火球的两个时刻，不是双发资产。
