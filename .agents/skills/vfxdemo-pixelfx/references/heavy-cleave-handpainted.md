# Heavy cleave · 保留运动的高清手绘刀光

适用于现有斩击手绘化，尤其是弧线波浪、色层碎多、刀面过平或笔触过齐的问题。
这是 Heavy cleave 的制作案例；方法可按参考选用，造型、色值、时间和笔触数量保留为案例参数。

## 作者选择与范围

2026-11-12，作者要求“保留该刀光效果，先不导入unity”，选定 V4 / 4.0.2；
随后要求将本次正向改动记录为 skill。保存源码、参数、预览和证据，继续处于制作阶段。
原版仅提取刀光，不包括人物、武器、蓄力闪光、落地爆点、裂纹、烟尘、碎石和火星。

| 输入 | 决定什么 | 本案保持或采用的内容 |
| --- | --- | --- |
| pixelfx 原版 Heavy cleave | 运动方向、倾斜弧面、锚点、节奏与余影 | 左上起势，顺时针越顶，向右下劈落，后段沿原弧追赶消退 |
| 作者红色刀光样例 | 高清手绘的画法 | 锋利外亮边、内侧撕裂、宽幅阴影、局部反光和顺势笔触 |
| 作者对前段单色区的标注 | 本轮细化目标区域 | 在完整宽头和刀面上补充厚度，不只装饰已有拖尾 |

V2 曾把画法样例的环形构图带入作品；V3 回到原版方向，V4 在其上细化表面。
沿用 V3 外弧、宽头、运动和时间，是本案防止风格细化改坏动作的边界。

## 有效的绘制改动

| 问题或目标 | 采用的画法 | 审稿重点 |
| --- | --- | --- |
| 像素台阶变成波浪 | 连续主弧直接重画；断口用明确切面、负形和不等长分叉 | 看外弧是否稳定，硬切是否有方向；不逐级圆滑每个像素台阶 |
| 过渡色带太多 | 合并为主色、暗部、局部反光、亮刃等少量语义分组 | 控制大面积关系，避免整圈等宽色带；不规定只能三种像素值 |
| 前段大片平色 | 用宽幅背光面与局部柔和转折覆盖前段刀面 | 同相位放大作者标注区，确认改善确实发生在前段 |
| 高光整齐、近似抛光表面 | 反光改成不等宽、长短不同且局部断开的笔触，端部渐细收笔 | 错开高光与细线的起止；保留空白，不堆平行刻线 |
| 需要柔和又保持锋利 | 柔和仅放在内部阴影/反光交界，外部窄亮刃独立绘制 | 深浅底都检查；主体不能被光晕吞没，也不整体模糊 |
| 补动态形变但不破坏方向 | 内部笔触随单次挥出拉伸、收尾回收，保持外弧不变 | 用实例年龄驱动，慢放看内部变化，原速确认仍像同一重击 |

本案宽头表达整刀长度，是作者指定的造型；前段整块、内沿/后段撕裂也是该刀光的设计。
其他斩击按自身参考决定前端是否尖锐、破碎分布和弧线形态，不套用本案宽头。

## V4 的具体实现与迭代

Canvas 几何沿用 V3 主运动和轮廓；表面用手工路径与局部渐变绘制宽阴影、反光，
少量有笔压变化的弧向笔触补细节。内部以单次时间包络拉伸回收，不以周期噪声扰动外弧。
这些是 Canvas 制作方法；不能据此声称已经完成 Unity Shader 或原生粒子验证。

| 轮次 | 实际改进 |
| --- | --- |
| V4 / 4.0.0 | 在原先单色前段加入体积阴影、暖色反光和长短不同的笔触 |
| V4 / 4.0.1 | 缩短并错开平行细线，降低局部细笔强度，反光改为不等宽的柔和笔触 |
| V4 / 4.0.2 | 宽反光离开前端切面渐细收笔，去掉齐整的高光端带，同时保住宽头 |

配色与强度独立可调，颜色层与加法微光分开。V4 新增阴影、笔触、内部形变强度；
默认参数和完整色值集中记录在作品 [AUTHORING.md](../../../../Tools/PixelFX/output/hd/HeavyCleave/V4/AUTHORING.md)
与 [checks.json](../../../../Tools/PixelFX/output/hd/HeavyCleave/V4/final/checks.json)，不复制成技能默认值。
