# BlueWisp V3 · 本机 Editor 探查基线

2026-11-12。状态：**本地基线已测**，不是目标设备预算通过版。
原始数据见 `PerformanceRaw.json`，聚合结果见 `PerformanceSummary.json`。

## 环境和方法

Unity 6000.3.19f1、URP 17.3 / PC_RPAsset、Linear、Metal、Apple M5、Editor。
2340×1080，正交相机 Size=4.9，HDR/MSAA 关闭，vSync=0。
保留工程设置；在真实 Play Mode 中暂时隔离已有作品，测试后恢复。

0/1/8/32 个重叠实例各重复两轮，另测8个分散实例。每阶段暖机0.8秒、采样2.2秒，
每隔一个实际引擎帧取样。计时期间没有截图或 Frame Debugger。
正常业务并发和目标预算未给定，这些数量仅用于探查，不是使用上限。

Editor 引擎帧推进较慢，约10fps，最终每组只有11–23个采样点；
P95尤其不稳定。以下为整帧计数器而非特效独占耗时，包含 Editor/探针干扰，
不能用这些数值直接换算实际帧率，也不能把空场差值当成确定的单实例成本。
此前后台稀疏运行另存为 `PerformanceRaw_BackgroundSparse.json` /
`PerformanceSummary_BackgroundSparse.json`，没有混入本表。

## 绘制、几何与内存

- 独立 Frame Debugger 诊断（`FrameDebuggerEvents.json`）：单体2条、8个实例16条
  DynamicGeometry 绘制事件，分别是主色块与MicroGlow；未观察跨实例合并。
- 主体预乘 Alpha 与微光 Additive 混合不同，保留2份共享材质。
  SetPass未随实例数等比例增长不代表Draw被合并。逐事件详细数据不可用，精确断批原因待查。
- 每实例2个原生粒子，4姿态共享Mesh8208顶点、12178三角形；微光4顶点、2三角形。
  非当前姿态在Shader中退化，不等于不执行其顶点处理。
- `VisualAndStructure.json` 中 Mesh资源内存820992 bytes，材质2480 bytes，无贴图。
  这是资源快照，不是完整运行/GPU内存。全Editor内存快照见聚合JSON，
  包含探针、克隆与Editor，未作长期池化或泄漏结论。

## 结论与缺口

本轮保留画面与两层混合，未进行无预算依据的结构重写；不声称生产优化完成。
目标Player/手机、Shader变体打包、业务并发/FPS预算、每Pass GPU/overdraw及长期池化内存未测。
后续需要优化时，应在确定平台、镜头和并发后，按同条件A/B并重新验收视觉。
